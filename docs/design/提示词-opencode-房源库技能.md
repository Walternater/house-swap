## 五、合并 deepseek 已有工程资产 → 收编为"房源库"技能（重要）

### 5.0 背景（必读）
- 项目：北京房产置换。工作空间 `/Users/wcf/personal/房产置换/`
- 现状：`收藏房源/` 已是统一房源库（44套贝壳数据：`房源数据.json` 主数据 + `房源数据.csv` 主表 + `房源对比分析.md/html` + `房源图片/44张`），由 deepseek 维护
- 贝壳反爬现状：**当前 IP 被 WAF 标记**（bj.ke.com 返回 CAPTCHA/403，302 至 hip.ke.com/captcha），但**图片 CDN（licdn）不反爬，URL 拿到即可直下**
- 目标：把 deepseek 的三个脚本**收编改造**成可独立安装、跨项目复用的"房源库"技能，并解决贝壳反爬

### 5.1 收编资产（勿重写，直接收编改造）
`收藏房源/scripts/` 下三个可工作脚本（仅依赖 Python3 标准库）：
- **add_listing.py（617 行）**：增量补录+双评分+点评生成+JSON/CSV/MD/HTML 四同步+主图下载。**能力清单必须全部保留**：
  - 双评分（市场×40%+适配×60%，`market_score`/`fit_score`/`composite_score`）
  - 逐套点评与置换测算（`gen_comment_md`：推荐标签+亮点+⚠️风险+首付/税费/月供测算）
  - 楼龄/贷款友好度（`loan_friendly`）、标题预填（`title_features`）、区域/小区子串识别（`find_xq_meta`）
  - `--url/--id/--title/--manual/--update/--dry-run` 全部行为
  - **自动分析文档（regenerate_analysis 生成的六章结构必须原样保留）**：
    ① 综合排序表 ② 区域分布画像 ③ 评分说明 ④ 关键洞察（预算内/电梯/满五/未满两年/楼龄受限自动统计）
    ⑤ 看房优先级 Top6 短名单 ⑥ 逐套点评与置换建议（44套全量）
- **build_html.py（237 行）**：从主数据生成可视化对比 HTML（AI点评列+楼龄标红+整体置换建议区），内部 `import add_listing` 复用
- **download_huxing.py（164 行）**：批量下载图集/户型图，含户型图标记（`_户型图` 后缀）、`--html` 离线模式、断点续传

### 5.2 两级抓取通道（核心设计，保留并细化）
- **Tier 1 快速通道**：沿用 urllib+UA 直抓（家庭宽带可用，每页<1s）——默认首选
- **Tier 2 浏览器通道**：检测到 302→hip.ke.com/captcha 或 clogin.ke.com 时自动升级。实现方式：本机浏览器自动化（Playwright 或 Chrome CDP）+ 用户已登录的贝壳会话（cookie/登录态），成功后把页面 HTML 回喂 Tier 1 解析器（**解析逻辑只写一份，吃 HTML 字符串**）
- 通道选择：默认 Tier 1，**连续 2 次被风控则本次运行永久切 Tier 2**；`--tier 1|2|auto` 强制指定
- **户型图链路**：Tier 2 拿到 HTML → `extract_images` 提取图片URL（含户型图）→ **走 licdn CDN 直下**（CDN 不反爬）
- ⚠️ 礼貌性要求：请求间隔 ≥0.5s、失败指数退避、并发 ≤2——**避免把家庭 IP 也搞封**（当前主 IP 已因此被封）

### 5.3 技能化改造清单
1. **路径解耦**：硬编码 BASE/房源数据.json → `--out` 参数+配置文件（默认 `./houses_db/`），技能可任意项目使用
2. **XQ_META 外置**：小区→(地铁,均价) 字典抽到 `xq_meta.json`；未知小区自动追加 `{"地铁":"待核实","均价":null}` 占位并提示
3. **CLI 统一单入口多子命令**：
   - `house scrape --urls links.txt`（两级通道批量抓）
   - `house add --url xxx [--update]`（增量补录，原 add_listing 能力）
   - `house images [--id xxx]`（图集/户型图，原 download_huxing）
   - `house build-html`（对比 HTML，原 build_html）
4. **评分权重进配置**（默认市场40%/适配60%）；双评分、点评、置换测算、画像统计、Top6 逻辑原样保留
5. 保留 `--dry-run`、`--manual`、抓取失败转手动确认
