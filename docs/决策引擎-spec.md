## 1. 双评分（0-100）

- 税费 15：满五唯一→15, 满五→11, 满二→7, 其他→2
- 楼龄 15：≤10年→15, ≤20→12, ≤25→9, ≤30→6, >30→2
- 电梯 10：有→10, 无→4
- 楼层 10：中→10, 低→7, 高→6, 顶→3
- 朝向 10：南北→10, 南→8, 东南/西南→7, 东/西→5, 其他→3

## 2. 资金测算

- 等额本息月供：PMT = P×r×(1+r)^n / ((1+r)^n - 1)，r=年利率/12, n=月数
- 卖房净得 = 成交价 - 中介费(可配1.5%-2.7%) - 增值税(满2年=0) - 个税(满五唯一=0 / 差额为负=0 / 核定1%)
- 现金回笼 = 卖房净得 - 房贷剩余
- 可用资金 = 现金回笼 + 手头现金
- 缺口 = (全清信用贷 + 首付15% + 税费约2%) - 可用资金
- 置换后月供 = PMT(公积金余额可用部分@2.6%) + PMT(商贷@商贷利率)，30年

## 3. 综合可行性指数（E2）

- 基础 60 分
- 缺口 ≤ 手头现金：+20；缺口 ≤ 现金+借款能力：+10；否则 -20
- 置换后月供/可支配 ≤ 30%：+10；30-40%：+5；>50%：-20
- 60万归本未结清：-10
- 指数 ≥80：强烈建议换 ｜ 60-79：可换需准备 ｜ <60：暂缓

## 4. 反向计算（E1）

- 目标月供 → 可贷总额 = 月供/PMT系数(30年@商贷利率)
- 可买总价 = 可贷总额 + 首付（可配比例）
- 输出精度 ±1万内

## 5. 三方案（E4）

| 方案 | 总价档 | 首付来源 | 月供占可支配 |
|---|---|---|---|
| 稳健 | 预算×0.83 | 现金为主 | ≤25% |
| 平衡 | 预算×0.93 | 现金+少量借款 | 25-35% |
| 激进 | 预算×1.0 | 借款较多 | 35-50% |

## 6. 边界（必须处理）

- 面积/价格/月供 ≤0：拒绝计算，提示
- 楼龄/年限缺失：按最保守（楼龄=30, 年限=未满二）
- 月供计算 n=0 或利率=0：降级为等额本金
